# Pine Scripts & Algorithmic Trading Toolkit

An open-source collection of quantitative analysis indicators, market structure detection modules, and execution automation helpers designed for TradingView and financial developers.

## Features
- **Market Structure Shift (MSS) Detection:** Automated identification of trend changes and break of structure (BOS).
- **Liquidity & FVG Tracker:** Real-time tracking of Fair Value Gaps, order blocks, and liquidity sweep zones.
- **Backtesting & Alert Utilities:** Clean data formatting and webhooks integration for algorithmic execution.
